# Code of Conduct

This project follows the spirit of the Contributor Covenant: be respectful,
assume good intent, and keep discussion technical and evidence-based.

- **Expected:** respectful review, honest reporting of limitations and
  failures, credit for data sources and prior work, no fabricated results.
- **Unacceptable:** harassment, discrimination, personal attacks, publishing
  others' private information, or misrepresenting simulation outputs as
  official data.
- **Scientific misconduct** (fabricated calibration, invented data,
  silently weakened tests) is treated as a conduct violation in addition
  to a technical one.

Reports: contact the project owner privately (see `SECURITY.md` for the
reporting channel). All reports are handled confidentially.
